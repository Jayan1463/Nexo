# Setup

1. Install dependencies with `npm install`.
2. Configure Firebase client values in `firebase-applet-config.json`.
3. Configure `.env` from `.env.example`.
4. Run `npm run dev`.
5. Sign up with Firebase Authentication.
6. Create or use the default organization and project.
7. Register a server and copy the one-time API key.
8. Start the monitoring agent.

Use `Demo Data` for classroom demonstrations without physical servers.
